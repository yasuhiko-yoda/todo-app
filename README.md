# Todo App

React + Spring Boot + H2 Databaseを使用したTodoアプリです。

## 使用技術

### Frontend
- React
- Vite

### Backend
- Java 21
- Spring Boot 4.1.1
- Maven

### Database
- H2 Database

## 開発環境

- IntelliJ IDEA
- Visual Studio Code
- Git / GitHub

## 機能

- [ ] ログイン
- [ ] Todo一覧表示
- [ ] Todo登録
- [ ] Todo編集
- [ ] Todo削除
- [ ] Todo完了状態変更
